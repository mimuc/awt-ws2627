# Counter – React (Vite)

`npm install && npm run dev` · tests: `npm test`

- `src/Counter.jsx` – the counter as a function component with `useState`
- `src/CounterClass.jsx` – the same counter as a class component (for comparison)
- `src/App.jsx` – uses `<Counter />` like a regular HTML element
- `src/*.test.jsx` – tests with Vitest + React Testing Library (setup: `test` section in `vite.config.js`)
